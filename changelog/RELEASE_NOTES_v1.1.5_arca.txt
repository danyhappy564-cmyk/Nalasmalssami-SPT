[SPT 4.1] 나랏말싸미 v1.1.5 — 아이템 태그 한글 입력 모드

■ 이 모드는?
- 아이템 태그에 한글을 쓸 수 있게 해 주는 클라이언트 모드입니다.
- 원래 게임은 태그 창에 한글을 치면 바로 지워 버리고, 저장해도 인벤토리 칸에서는 빈 막대로 보입니다. 둘 다 해결했습니다.
- 태그 창 입력 칸에만 적용됩니다. 닉네임 같은 다른 입력 칸은 건드리지 않습니다.

■ 기능
- 한글 태그 입력 (조합 중인 마지막 글자도 저장됨)
- 인벤토리 칸에 한글 태그 표시
- 태그를 이름 위에 — 태그가 있으면 아이템 짧은 이름을 숨겨서 태그가 안 잘림 (FalconPilot 님 원작)
- 태그 색상 확장 — 7색 → 18색 + 회색 9단계, 색은 F12에서 직접 지정 (acidphantasm 님 원작)
- 태그 글자색 자동 대비 — 노랑·밝은 회색 막대에는 검은 글씨
- 태그 프리셋 버튼 — "팔 것", "퀘템" 같은 버튼을 누르면 글자·색이 바로 들어감
- 태그로 창고 검색 — 돋보기 검색에서 태그로도 찾음, #검색어 는 태그만
- 태그 글자 크기·굵기·모양·위치 조절
- 모든 설정은 F12에서 바꾸는 즉시 적용 (인벤토리 다시 열 필요 없음)

■ 1.1.5 변경점
- 태그 글자 굵기가 오락가락하던 문제 수정
  (아이템을 옮기면 얇아지고 메인 메뉴를 다녀오면 두꺼워졌습니다. 굵게 설정이 아니라 한글을 그리는 글꼴이 그때그때 달라서였습니다. 이제 설정 하나로만 정해집니다.)
- 새 설정 "태그 한글 모양": 깔끔하게(테두리 없음, 기본) / 이름 글자처럼(테두리)
- "태그 글자 굵게" → "태그 글자 굵기": 게임 기본 / 굵게 / 안 굵게
  (예전엔 꺼도 굵게 보이는 경우가 있었습니다.)
- 태그 글자 위치 조절 추가: 좌우·위아래 각각 -10 ~ 10픽셀, 색 막대는 그대로 두고 글자만 이동
- 1.1.5 변경분은 아직 인게임 확인 전입니다. 이상하면 아래 "문제가 생기면"대로 로그 부탁드립니다.

■ 설치
- Nalasmalssami-1.1.5.zip 을 SPT 폴더에 풀면 끝입니다.
  → BepInEx\plugins\Nalasmalssami\Nalasmalssami.dll
- 클라이언트 전용, 서버 모드 없음
- 이전 버전에서 올리면 덮어쓰기만 하면 됩니다. 설정은 그대로 남습니다.
  (예전 "태그 글자 굵게" 체크만 "태그 글자 굵기 = 게임 기본"으로 새로 시작합니다.)

■ 호환성
- SPT 4.1.6에서 테스트
- 원본 모드(TagOverName, MoreTagColours)와 같이 깔아도 충돌하지 않습니다. 원본이 있으면 겹치는 기능은 자동으로 꺼지고 원본이 처리합니다.
- 고라니 한글화(Korean Patch Fix 2.1.1)와 같이 쓰는 환경에서 확인했습니다.

■ 주의
- 태그 색은 번호로 저장됩니다. 색상 확장을 끄거나 모드를 빼면 8번 이후 색 태그는 1번 색으로 보입니다. 다시 켜면 원래 색으로 돌아옵니다.
- 모드를 빼도 한글 태그 글자는 프로필에 남습니다. 다만 그 태그 창을 다시 열면 게임 기본 규칙이 한글을 지울 수 있습니다.

■ 문제가 생기면
